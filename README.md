# Skyscanner Front-End Engineering Task

This project was completed as part of the Skyscanner Front-End Software Engineering Virtual Experience Program on Forage.

## Overview

The task involved reviewing the Skyscanner design system and calendar component documentation, then implementing and integrating new features into the application.

## Features

- Integrated Skyscanner calendar component
- Added new functionality to the app
- Improved user interaction and UI behavior
- Built using JavaScript and front-end development principles

## Technologies Used

- JavaScript
- Sass
- React

## Challenges Faced

One major challenge during this project was resolving dependency and build configuration issues after installing React, ReactDOM, and Backpack packages.

After running the project, the application failed to render correctly and produced build/startup errors. Troubleshooting involved:

- Investigating package compatibility issues
- Resolving missing Babel dependencies/plugins
- Fixing development environment configuration problems
- Reviewing package installations and project setup

This experience improved my debugging skills and helped me better understand how React build tools and dependencies work together in a real-world project environment.

## What I Learned

Through this project, I learned how to:

- Work with technical documentation
- Integrate third-party UI components
- Improve problem-solving skills in frontend development
- Understand real-world engineering workflows
